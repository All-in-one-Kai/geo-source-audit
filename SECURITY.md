# Security reporting

Do not post credentials or security-sensitive reproduction data in public issues.
Send a minimal, sanitized description to kai@ki-agenten.shop, naming this repository
and affected revision. Do not send passwords, API keys, customer records or private files.
We will ask for an appropriate private follow-up if more detail is required.
Only the latest public revision is actively maintained, on a best-effort basis.
Do not probe third-party accounts or incur provider charges as a proof of vulnerability.
